# NETO

Rebuilt voice-first AI companion.

Features:
- Typed chat with visible messages and AI replies
- Browser speech recognition for voice input
- Browser speech synthesis for voice replies
- PWA manifest and standalone display
- In-app install prompt where supported
- Settings panel with a direct Home button

Setup:
1. Copy `.env.example` to `.env`
2. Set `GEMINI_API_KEY`
3. Run `npm install`
4. Run `npm run build`
5. Run `npm start`
